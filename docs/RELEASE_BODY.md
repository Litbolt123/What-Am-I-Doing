# What Am I Doing 1.2.5 — Windows installer

## What's new

### Appearance
- **Dark mode** — Settings → Appearance → **Dark mode** applies a dark dashboard, Settings, Rules, and other themed windows. Toggle off to return to light without restarting.
- **Dark mode polish** — themed scrollbars; readable dropdown menus (Range, Match when, etc.); **Category** and other editable combo boxes show typed/selected text; split **Refresh** button hover fixed; chart legend colors follow the theme.

### Settings
- Saving appearance options no longer shows a spurious **Restart helper** warning when you were only changing theme (watchdog prompt appears only when newly enabling **Restart if not running** and Task Scheduler registration fails).

### Rules
- Built-in suggestions for **Hytale** / **HytaleClient** → Gaming category.

## Notes

- Quit the app from the tray before running the installer.
- Updating over **1.2.4** keeps your activity database and settings.
- **DatePicker** calendar popup styling in dark mode is still a known cosmetic gap (day field works; calendar chrome may look mixed).
